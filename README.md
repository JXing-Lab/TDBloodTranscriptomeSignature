# Whole-Blood Transcriptome Profiling Revealed Gene Expression Signatures of Tourette Disorder

This is the code repository for the paper "Whole-Blood Transcriptome Profiling Revealed Gene Expression Signatures of Tourette Disorder".

1. The raw data is deposited at the NIMH Data Archive (NDA) Collection C2958. 

2. Each folder has its own README file.

3. bash scripts in ./sh generate RSEM gene counts

4. R scripts in ./R use the gene counts to check quality, compute DEGs and identify biomarkers
